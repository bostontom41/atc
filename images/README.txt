Drop your photos in this folder using these exact file names.
Anything missing shows a grey placeholder until you add it.

logo.png       - your logo (light/white version works best on the navy header)
favicon.png    - small square icon for the browser tab (optional)
hero-1.jpg     - main hero photo (wide, finished project)
hero-2.jpg     - hero small photo (crew on site)
hero-3.jpg     - hero small photo (work in progress / before-after)
about.jpg      - team or owner photo
project-1.jpg  - project card 1 (water damage)
project-2.jpg  - project card 2 (rebuild)
project-3.jpg  - project card 3 (renovation)

Tip: keep each photo under ~500 KB (about 1600 px wide) so the site loads fast.
